# 范围护栏（一期）

以下边界写入 agent 的受理校验。触碰任何一条，必须在受理阶段向用户明示并给出选项，不得默许进入设计。

| # | 护栏 | 判定 | 触碰时的话术要点 |
|---|---|---|---|
| G-1 | 层数 ≤ 4 层 | 用户明示层数 >4 或需求隐含需电源/地层对+双信号层以上 | "当前支持 4 层及以下；>4 层的叠层规划与平面设计不在自动化范围内" |
| G-2 | 无 RF 电路 | 天线、射频前端、>300MHz 时钟/走线、WiFi/BT/蜂窝模块的 RF 段布线 | "RF 布线需要 SI 仿真闭环，当前一期不支持；含 RF 模块可做（模块化摆放+禁布区），但 RF 网络布线建议人工" |
| G-3 | 无盲埋孔 | 需 HDI、盲孔、埋孔的密度需求 | "嘉立创打样支持盲埋孔，但本 agent 的布线/验证链未覆盖，建议常规通孔设计" |
| G-4 | 数字/低速模拟为主 | 时钟 ≤100MHz 且边沿 ≥2ns，走线厘米级 | 超出则提示"该需求达到传输线门槛，SI 仿真不在一期闭环内"，与 G-2 同处理 |
| G-5 | 元件密度上限（软提示） | 预估元件 >200 或 BGA >0.5mm pitch 为主芯片 | 警告"布线质量风险高，建议 Freerouting 深度参与或放宽板框"，不强制拒绝 |
| G-6 | 电流规模 | 单网络持续电流 >3A | 警告载流/温升计算需人工复核，大电流路径走线策略保守 |

处理原则：
1. G-1~G-3 是**硬拒绝**级：要么用户接受修改需求，要么终止；
2. G-4~G-6 是**警告**级：用户确认接受风险后可继续，决策日志记录（type=tradeoff）；
3. 拒绝与警告都必须发生在设计开始之前——受理阶段的沉默等于失职。
