# 教学讲义生成（Teaching Lecture）

## 启用条件（缺一即停）

1. MISSION.md 交付物中"教学讲义"已勾选；
2. 工程已完成 G6（制造文件交付）——讲义必须基于**已验证**的工程，不给半成品写教案；
3. `doctor.py` 中 xelatex 级检查通过（未装则提示安装 TeX Live/MiKTeX，装包需用户确认）。

## 粒度规范（对齐教研需求，读者=已修数电/模电/嵌入式/焊接/电子实验的学生）

- **可直接使用专业术语**（共阻抗耦合、开尔文接法、零极点补偿），不解释基础概念；
- 公式推导完整，设计依据必须引用 datasheet 原文/章节；
- **逐模块章 = 导读 + 五段式 + 小结**：章首 `introduction` 导读（学习目标，动词开头）→ ① 功能用途 → ② 工作原理 → ③ 设计依据与计算 → ④ PCB 布局布线要点 → ⑤ 验证方法与结果 → 章末 `conclusion` 小结；
- **总览章**：需求→指标追溯表、电源树与信号流、板级布局策略、模块间接口（GND 划分/单点连接）、整体验证计划与结果汇总；
- 可选附录：PCB 通识规则清单（层定义、线宽-电流表、去耦/储能电容分档、DRC 纪律）——默认不含，面向低年级才加；
- **禁习题**：讲义不含练习题/自测题/章末习题（用户决策 2026-10-19），不使用 exercise/problemset 环境；
- 每个数值/公式标注状态徽标（见下）。**徽标的"出处"写自然语言结论，不写内部文件路径**——见下节纪律。

## 内容边界纪律（"讲义 ≠ 工作日志"，2026-10-22 委托方意见固化）

**读者是来学电子设计的，不是来学我们怎么干活的。** 凡与电子设计主题无关的内容**一律不得出现在讲义里**。

**必删清单（六类）**：
1. **站与流水线**：`G3 站`/子 session/主 session/子代理/任务书/胶囊/交接/各站；
2. **决策编号与日志路径**：`D0xx`/`决策 D0xx`/`logs/decisions.md`；
3. **证据文件路径**：`reports/…`/`spec/…`/`*.json`/`pitfalls`/`waivers`/`capsule`；
4. **豁免与验收流程**：`豁免`/`W-0x`/`验收口径`/`清零`/`门禁`/`零漂移`/`由 D0xx 裁决`；
5. **人机交互过程**：`委托方`/`用户指示`/`用户要求`/`我方`/`待裁决`/`授权`；
6. **工具与自述流程**：`脚本`/`工具链`/`自动化`/`质检器`/`回链`/`自检`/`逐页`/`agent`。

**核心手法：把"哪个文件记录了"换成"实测出的数值或结论"。**
- ❌ `\verified{reports/\_g5f\_width\_effective.json}` → ✅ `\verified{逐段实测}`
- ❌ `\verified{决策 D047 的几何闸门结论}` → ✅ `\verified{实测：最小间隙 0.522\,mm}`
- ❌ `委托方明确要求把接口改成 2.54\,mm 排母，理由是…` → ✅ `接口选用 2.54\,mm 排母，理由是…`（**设计理由要留，只删"谁要求的"**）

**必须区分两类"约束"**：
- ✅ **电子设计约束要留**（线宽分档、板边距、禁铜区、ADC 链长度、不换层、手焊工艺…）——这是**读者要学的设计规范**；
- ❌ **管理约束要删**（D 编号、豁免流程、证据路径、谁拍板）——这是**我们的内部过程**。

**错例警示盒的语气**：写成"**你**容易在哪错"，不是"**我们**当初错在哪"。技术内核保留（正确判据是什么、为什么会错、正确做法），叙事视角换成读者。

**自查**：生成后扫描"过程性内容"命中数（可参考 `scripts/g7/g7_workflow_audit.py`），**目标 <60 处、占比 <5%**；残留逐条清零或说明为何无法改写。
**篇幅会因此缩短，这是对的——不要为凑页数加内容。**

## 版式纪律（v2，违反即质检 FAIL）

- **必含环境七件**：`introduction`（导读）、`definition`（核心概念，1–2 个）、`proposition`（编号设计规则，1–3 个）、`misconception`（错例警示，唯一自定义盒，1–2 个）、`example`+`solution`（worked example，1 个）、`note`（模型可得性等注意事项）、`conclusion`（小结 3–5 句）；
- **盒子通胀禁令**：除上述内置环境与唯一自定义盒 `misconception` 外不得再加盒子；教学盒子只用 ElegantBook 内置 + misconception；
- **状态徽标**：状态一律用 `\verified{依据}`/`\computed{依据}`/`\estimate{依据}`/`\notestablished{依据}` 徽标命令（定义在 main-demo.tex 导言区），禁止括号文字裸写状态（表格"状态"列可用纯文本）。**徽标内容写自然语言依据**（"逐段实测"/"按式 (2.1) 复算"/"实测：最小间隙 0.522\,mm"），**不写 D 编号与文件路径**；
- **AI_INFERRED 语义**：agent 推导且未经任何佐证（datasheet/仿真/计算书）的内容一律标 `\notestablished`，不得伪装成 `ESTIMATE`——ESTIMATE 特指"按手册/经验取值但未独立复算"；
- 错例警示盒固定三行式：**错误做法 → 后果 → 正确做法**，素材优先取 pitfalls.md 陷阱清单；
- 图必须有编号与正文引用；图表必须有编号与正文引用。

## 两段式生成流程

1. **蓝图**：按 IR 模块树生成讲义目录（总览 + 逐模块五段卡片清单），**每章附学习目标列（Bloom 动词：记住/理解/应用/分析）**→ AskUserQuestion 请用户确认目录、粒度与深浅；
2. **逐章生成**：每章按 `module-chapter-skeleton.tex` 骨架成稿（七件套占位逐个填实）；每章上下文 = 该模块产物切片（模块原理图/布局截图、仿真波形、`logs/decisions.md` 相关条目、`reports/module-<id>.md`、datasheet 引文）→ 五段成稿 → 组装；生成前先读样例章 `sample-chapter-tps40200.tex` 校准深度与版式；
3. **质检**（不可跳过）：
   - `python "${CLAUDE_PLUGIN_ROOT}/scripts/teaching/tex_quality_check.py" teaching/*.tex`
   - **事实性核对（内部做，不写进讲义）**：抽出文中每个数值/公式，**在决策日志/验证记录/计算书中 grep 到出处**，确认不是编的；断链的段落重写。
     ⚠️ **核对是内部动作，出处本身不写进讲义**——写进讲义的是**结论**（如"实测：最小间隙 0.522\,mm"），不是**文件路径或 D 编号**。否则讲义会退化成工作日志（见上节纪律）。
   - **内容边界自查**：扫描过程性内容命中数（站/流水线、D 编号、证据路径、豁免流程、人机交互、工具自述六类），**目标 <60 处、占比 <5%**，残留逐条清零。
   - 附图核对：figures/ 中每个图文件非空、时间戳晚于工程最后修改。
4. **编译**：工作区路径含空格/中文时，先拷贝到 ASCII 临时目录再编译（`mktemp -d`）；`xelatex` 连跑 2 次（目录/交叉引用）；失败自查三类错（tex 语法、图路径、字体）。
5. **渲染评审**（不可跳过，但**要分级**——别把验收做成 marathon）：
   - **第 1 轮（首次，必须全本）**：PyMuPDF 逐页渲染 PNG，**全本**过一遍——文字溢出/孤行、图注与图分离、盒子跨页断裂错位、徽标渲染缺失、表格超宽；
   - **第 2 轮起（只查改动）**：**只复查上一轮判 fail 的页 + 与改动相邻的页**，不要重扫全本；
   - **判定收敛的信号**：同一类缺陷连续两轮没有新增 ⇒ **停止评审，进入交付**，把剩下的 minor 如实写进质检报告的遗留表即可（不要为 minor 继续开轮次）。
   - **评审预算**：一个交付物**最多 3 轮**；到第 3 轮仍有 major/major 级问题，就**如实记为遗留并报给委托方裁决**，而不是继续无限修。
   - 理由：评审的价值在**首轮抓系统性缺陷**（如 22 处 `footnotes` 泄漏）；次要排版瑕疵（留白、列宽、个别标注贴边）**不值得再开一轮全本扫描**。
6. **交付**：`teaching/lecture.pdf` + `teaching/lecture.tex` + figures/ + 附录仿真复现包（CircuitJS1 `.cct` 文件 + 复现说明；PDF 内放链接/二维码）。
6. **交付**：`teaching/lecture.pdf` + `teaching/lecture.tex` + figures/ + 附录仿真复现包（CircuitJS1 `.cct` 文件 + 复现说明；PDF 内放链接/二维码）。

## 模板与样例

- **逐章骨架**：`${CLAUDE_PLUGIN_ROOT}/templates/teaching/module-chapter-skeleton.tex`（七件套占位，生成任何模块章前必读）；
- **导言区**：`${CLAUDE_PLUGIN_ROOT}/templates/teaching/main-demo.tex`——徽标命令（\verified 等）与 misconception 盒定义在此，组装 lecture.tex 时必须携带该导言区；
- **粒度样例章**：TPS40200 DC-DC 主体电路（与教研课程对齐）——生成前先读它校准深度与版式；
- 语言风格：陈述句、给出"为什么"；禁止营销腔与"综上所述"式空话。
