PCB-Wish 是一个面向 PCB 设计的桌面智能体系统。用户用自然语言描述硬件目标，系统依次完成需求澄清、器件选型、原理图设计、PCB 布局布线与检查验证，最终输出 Gerber 光绘文件、钻孔文件、物料清单（BOM）、贴片坐标和检查报告。当用户明确提出需要教学讲义时，系统还会在制造文件完成后自动生成一份 LaTeX 排版的 PDF 讲义。

项目基于国产开源框架 ZCode 进行任务特化的修改（领域插件位于 `apps/zcode-cli/packages/pcb-wish-plugin/`），设计执行则依托国产嘉立创EDA专业版（LCEDA Pro）。

嘉立创作为国内主流的 PCB 平台，其 EDA 工具的适用范围恰好契合本项目的目标场景；生态涵盖开源硬件社区与立创商城，可实现一站式打板。系统全面接入立创商城官方 API 与嘉立创EDA API，从立创商城检索选型，到在嘉立创EDA中绘制原理图、PCB 与布线，覆盖了从元器件选型到制造文件的全栈工作。同时，ZCode 作为国产开源项目，提供了完善的智能体框架与原生交互体验，结合嘉立创本土生态，共同实现了面向硬件的“许愿式开发”。

## 创作背景

本项目的灵感源于《工科创》课程的教学全过程。工科创课程中已经涉及电子设计、板卡绘制等基础内容，但受限于统一的课程安排，难以覆盖每位同学各自不同的需求与探索兴趣。许多同学在修完课程、具备一定电子基础后，往往希望亲手制作一块自己真正感兴趣的功能板卡，却容易在器件选型、参数计算和制板流程上遇到困难。

受此启发，笔者希望借助当下快速发展的大模型技术，把电子设计学习与同学们感兴趣的项目结合起来，让它成为一个兴趣驱动的自主学习工具。通过将笔者完整的实际打板流程融入智能体（Agent）系统，项目既希望帮助同学们把脑海中的硬件想法落地为实物板卡，也希望通过随附生成的教学讲义，引导同学们在动手实践的过程中学习数值计算、元器件选型等电子设计方法，将“AI + 教与学”真正落脚在这一过程中。

围绕这一初衷，用户只需用自然语言描述一块绘制难度适中的目标板卡，系统即可通过分阶段工作完成需求澄清、选型、原理图与 PCB 绘制以及检查验证，并导出可交付制造的工程文件；当用户明确要求时还会生成配套教学讲义。本项目的板卡设计与交付流程全部使用国产生产工具：桌面端基于 ZCode 开源框架进行任务特化修改，设计执行使用嘉立创EDA专业版。

## 核心能力

- **对话式受理。** 用日常语言描述板卡；系统集中列出影响设计的参数缺口，最多提问两轮，并生成可自动校验的 `MISSION.md`。
- **分阶段门禁。** 按 G0–G7 逐门推进，每道门禁均要求对应的证据文件；未通过时自动修正或暂停，不带着缺口进入下一阶段。
- **独立质检。** 质检由独立智能体以只读方式复核：重新读取画布、执行网表检查、解析 Gerber，不直接采信设计角色的口头结论。
- **EDA 执行。** 驱动嘉立创EDA专业版完成建库、原理图绘制、布局、布线、铺铜与丝印，并导出制造文件。
- **制造交付。** 输出 Gerber、钻孔、BOM、贴片坐标、装配说明与检查报告，交付路径为 `projects/<slug>/export/`。
- **教学讲义。** 仅当用户显式要求时生成：采用总览章加模块章结构，逐章讲解工作原理、设计依据、布局布线要点与验证结果。
- **可追溯。** 决策日志、门禁状态与验证记录保存在 `logs/`、`reports/` 下，作为设计、复核与讲义编写的事实依据。

## 工作流程

```text
需求
  │
  ▼
受理 + 选型（G0 / G0.5）
  │
  ▼
设计（G1–G5.5）
  │
  ▼
独立质检（G6）
  │
  ▼
交付：Gerber、钻孔、BOM、贴片坐标、检查报告
  └── 教学讲义（G7，用户显式要求时）
```

`MISSION.md` 是项目唯一事实源；门禁状态记录在 `projects/<slug>/reports/gates.json`，每道门禁均有对应的证据文件与检查记录。

## 快速开始

1. 准备 Windows 10/11 64 位、嘉立创EDA专业版（≥ 4.1.60）、Python 3.10+。
2. 双击 `PCB-Wish-3.16.2-win-x64.exe` 按提示完成安装。
3. 首次启动填写 API Key。接口需兼容 OpenAI，模型需支持工具调用，上下文长度建议 1M；配置仅保存在本机。
4. 选择工作区，用自然语言描述目标板卡；系统会集中提问以补齐设计参数缺口。
5. 设计按 G0–G7 逐门推进；交付物位于 `projects/<slug>/export/`，交付说明为 `reports/DELIVERY_FINAL.md`。

从源码运行桌面端：

```bash
pnpm bootstrap
pnpm dev:desktop
```

## 教学讲义

教学讲义不是默认交付物。只有用户在受理阶段明确要求生成教学讲义，它才会进入 `MISSION.md` 的交付物清单；若未明确说明，受理智能体可能会询问是否需要，未确认或未选择时不生成，并在交付说明中注明。用户要求讲义后，系统会在板卡通过 G6 制造检查后生成 PDF。

当前讲义为 1 章系统总览加 7 个功能模块章，每章按“内容提要、工作原理、设计依据与计算、PCB 布局布线要点、验证方法与结果”五段式展开。FlexiHeal v2 讲义共 58 页、27 张真实工程图，文中关键数值尽量对应到实测、计算或仿真记录。

## 适用范围与当前边界

- 适用范围：2–4 层、低速数字与模拟、中小密度板卡；超出范围的高速、射频或盲埋孔需求会建议简化或分期实现。
- 布线以自动布线为主，辅以脚本修补；美观度、成本、电磁兼容、热设计等仍需人工工程判断。
- 下单、付款、对外沟通与最终签字由用户负责；投产前需人工复核封装、极性、BOM，并完成嘉立创可制造性检查。
- 受预算限制，目前已完成一次完整的人工在环测试（FlexiHeal v2）；完全无人干预的连续运行尚待更多样本验证。教学讲义目前仅展示内置默认技能包的产出，与其他开源技能包的组合效果尚未展示。
